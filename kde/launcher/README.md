# Nobara Enhanced launcher (Kickoff fork `local.lpnovi.kickoff`)

The top-panel launcher on the source laptop is **not** stock Kickoff. It is a user-local QML fork,
`local.lpnovi.kickoff`, built from the exact plasma-desktop **6.7.4** Kickoff source plus a set of
styling patches. It keeps `X-Plasma-Provides: org.kde.plasma.launchermenu`, so Meta and Alt+F1 still open it.

A fork is needed because Plasma 6 compiles Kickoff's QML into
`/usr/lib/qt6/plugins/plasma/applets/org.kde.plasma.kickoff.so`, so a same-id user copy can't override it.
Also, the Breeze-blue hover/focus comes from the Plasma Style's `colors` file, and KSvg ignores
Kirigami.Theme overrides, so those SVG states are redrawn in QML inside the launcher only.

## Files
| Path | What |
|---|---|
| `upstream-6.7.4/` | pristine Kickoff source from `plasma-desktop-6.7.4.tar.xz` (GPL-2.0-or-later / LGPL-2.0-or-later) |
| `nobara/` | new files: `NobaraStyle.qml` (palette, radius 10, 130 ms), `NobaraHighlight.qml`, `NobaraToolButton.qml`, `NobaraScrollBar.qml`, `NobaraHeadingBackground.qml`, `metadata.json` |
| `build.py` | copies upstream + applies exact, checked string patches → `~/.local/share/plasma/plasmoids/local.lpnovi.kickoff/` (override with `KICKOFF_OUT=…`) |
| `nobara-changes.diff` | reference diff of the built result against upstream (regenerated by `scripts/backup.sh`) |
| `apply.sh` / `revert.sh [--purge]` / `swap-launcher.py` | switch the existing panel applet's `plugin=` line between fork and stock (plasmashell is stopped while doing it) |

The built package is **not** committed; it is generated. `build.py` output was verified byte-identical
to the live install on the source laptop.

## Install
`./install.sh` (repo root) builds it and the panel layout script uses it automatically. By hand:
```bash
python3 kde/launcher/build.py                 # build/refresh the fork
kde/launcher/apply.sh                         # switch an existing Kickoff applet to the fork
systemctl --user restart plasma-plasmashell   # after rebuilding
```

## Revert
```bash
kde/launcher/revert.sh           # stock Kickoff back (same applet id, settings, favorites)
kde/launcher/revert.sh --purge   # ...and delete the fork from ~/.local/share/plasma/plasmoids
```
(On the source laptop the same scripts live in `~/.local/share/nobara-enhanced-launcher/`.)

## Changes vs stock Kickoff (visual only; models, keys and actions untouched)
- Launcher-scoped Kirigami accent: highlight `#6c54aa`, hover `#7a63c0`, focus `#8c73d2`
- Rounded (10 px) purple item highlight for grid tiles, list rows, sidebar, places and search results; selection cross-fades (130 ms)
- Sidebar: current category = purple pill (~20 % stronger than the app selection); hover-only = faint tint
- Search field: rounded dark field, violet border when focused, purple text selection
- Footer tab indicator: rounded pill instead of the blue underline
- Header/footer tool buttons: QML rounded frames with purple hover/pressed/checked/focus; same metrics
- Scrollbar: slim rounded handle, violet on hover; same 18 px metrics
- Header/footer bands redrawn in QML (black 75 % fill + 15 % hairline) with 10 px outer corners; pin band `#000000`
- Softer separators: 7 % white hairlines, inset
- App icons scale 1.06 (grid) / 1.05 (list) on hover, 130 ms OutCubic (transform, no layout shift)

## Plasma updates / CachyOS
The fork is frozen at 6.7.4 and depends on the shared `org.kde.plasma.private.kicker` models.
Arch/CachyOS ships Plasma **6.7.5** at the time of writing; the only Kickoff change in 6.7.5 is one line in
`KickoffGridView.qml` (`reuseItems: true` → `false`, a bug fix for model switching), so the fork works
as-is. If a later Plasma breaks it (launcher fails to load), run `revert.sh`. To rebase: put the new Kickoff
source (`applets/kickoff/` from plasma-desktop) into `upstream-<ver>/`, point `UP` in `build.py` at it, run it.
The build aborts on any patch that no longer matches instead of producing a half-styled launcher.
