# Wallpapers

No images are included. The originals are copyrighted game screenshots, so they can't be
redistributed. The look relies on **dark, desaturated, low-contrast** images that suit the
purple accents: a misty violet forest scene on the desktop and a grey night sky with a moon
on the lock and login screens.

To use your own, drop them here (images in this folder are git-ignored):

| File | Used for |
|---|---|
| `desktop.jpg` (or .png/.webp) | desktop, set by `scripts/install.sh` step 7 |
| `lockscreen.jpg` | lock screen, set by step 8 (`kde/config/kscreenlockerrc.ini`) |

The login screen (Plasma Login Manager) is set by hand: System Settings → Login Screen.
