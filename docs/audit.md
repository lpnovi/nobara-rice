## Panels (`plasma-org.kde.plasma.desktop-appletsrc` + `plasmashellrc`)
- Top: kickoff (custom icon) · Window Title Reborn · spacer · media controller · system tray · weather · clock; 36 px, translucent, dodge windows, floating applets.
- Bottom: icon task manager with 9 pinned launchers; 50 px, floating, fit content, translucent, dodge windows.

## Other user-made customization
- **Ghostty:** `~/.config/ghostty/config.ghostty` + `themes/nobara-enhanced`.
- **InputActions:** `~/.config/inputactions/config.yaml` (4-finger swipe = volume).
- **rEFInd:** staging/build folder `~/refind-nobara-theme/` (theme `nobara-purple`, build scripts, phase scripts and logs). The live copy is in `/boot/efi/EFI/refind/` (root-only), plus `/boot/refind_linux.conf`. NVRAM BootOrder has rEFInd first, then Fedora shim, Windows and fallback. Backups are in `/var/backups/refind-install-20260925/`.
- **GRUB:** Catppuccin theme at `/boot/grub2/themes/catppuccin` (from `~/grub`), `GRUB_TIMEOUT=12`, `GRUB_GFXMODE=1920x1200,auto`.
- **Plymouth:** `text` (nothing custom).
