# Live audit of the source laptop

Snapshot taken **2026-10-02**, read-only (`kreadconfig6`, file listings, `rpm -q`, and KWin's D-Bus
`loadedEffects`). Nobara Linux 44 (KDE Plasma Desktop Edition) · **Plasma 6.7.4 · KWin 6.7.4 · Qt 6.11.2 ·
Wayland** · 2880×1800 laptop panel. `~` = the user's home. This file supersedes the 2026-09-25 audit.

Classification used below: **[P]** portable config · **[U]** user-local KDE/Plasma/KWin resource (in repo) ·
**[X]** external package/dependency · **[T]** external theme/resource · **[M]** machine-specific (not migrated).

## What was missing/outdated in the repo before this update (2026-09-25 → 2026-10-02)
- Plasma Style recorded as Nobara-Enhanced; live is stock **Nobara** (and CachyOS has no Nobara package → now vendored).
- Colors recorded as stock Nobara; live is **NobaraEnhancedPurple**. App style recorded as Breeze; live is **kvantum** (`frameContrast` 0.2 → 0.12).
- Missing entirely: Kvantum theme + generator, color scheme, Kickoff fork, Task Icon Hover plasmoid, Quick Tile Glide effect, PlasMusic Toolbar (repo still had the stock media controller), Window Title Reborn files (only a store link), tiling layout in the installer, panel opacity/floating-applets/tray settings (were "set by hand").
- Installer and docs were Fedora/`dnf`-only; rounded-corners instructions were Fedora build deps.

GRUB config (`/etc/default/grub`, Catppuccin GRUB theme in `/boot/grub2/themes/catppuccin` — Nobara/GRUB-specific),
